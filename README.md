# Green integration by contradiction

Research materials and chapter development files.

## Interactive mind maps

Edit Markdown sources in [`mindmaps/`](mindmaps/), then run:

```bash
npm install
npm run build:maps
```

The generated static site is written to [`docs/`](docs/). GitHub Actions rebuilds and publishes it to GitHub Pages after changes to the map sources.

On Windows, double-click [`actualizar_mapa.bat`](actualizar_mapa.bat) to build locally. The script asks before committing and pushing to GitHub.

See [`mindmaps/README.md`](mindmaps/README.md) for the short workflow.
